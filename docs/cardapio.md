# Sincronização com o PDF oficial

- Origem: PDF de cinco páginas fornecido pela pizzaria.
- Pizzas: 79 produtos, com quatro preços cada; bebidas: 17 registros individualizados a partir dos itens listados (algumas bebidas estão agrupadas no PDF).
- Duplicidade: código impresso 109 designa tanto M&M's quanto Churros. No sistema: `109M` e `109C` / `120`. Digitar `109` isoladamente é ambíguo.
- Item Light/Tarantela e refrigerante em lata foram retirados porque não aparecem no documento recebido.
- O PDF físico deve ser colocado no repositório em `assets/cardapio.pdf`. O chatbot já foi preparado para enviá-lo.
- Dados e estoque são apenas demonstrativos, não prontos para operação comercial.
